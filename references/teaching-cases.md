# Local teaching case pack

The reviewed teaching images and verbatim expert records remain local and are not
distributed here. Recognition-rule reference IDs identify the source cases in that
pack; they are not links to public images.

| Reference IDs | Reviewed source distinction |
|---|---|
| ppt-s10-i1/i2, ppt-s11-i1, ppt-s13-i1, ppt-s17-i1, ppt-s23-i1 | Vehicle examples |
| ppt-s12-i1 | Vehicle and gerbil regions |
| ppt-s14-i1 | Gerbil and Tarim hare regions |
| ppt-s14-i2 | Gerbil and earthquake-like regions |
| ppt-s15-i1/i2/i3/i4 | Alternate views of the same hare/gerbil pair |
| ppt-s16-i1/i2 | Sheep-flock examples |

To supply a local pack, retain the reviewed labels, exact expert descriptions,
normalized region boxes, image paths, and provenance (revision and source hashes).
Identify each event's region when one image contains multiple sources. Original
titles and on-image labels may be wrong. Missing text time fields are acceptable
when a reviewed region is present.

Open the supplied images before claiming visual comparison with these cases.
Without them, state that the available evidence is the written rules only. The
synthetic rendering example in `examples/` is not a replacement teaching case.
